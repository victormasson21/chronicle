# data/snippets.json

Generated by `scripts/export-notion.mjs`. Do not hand-edit; fix the row in Notion and re-run.

```json
{
  "exportedAt": "2026-10-21T10:00:00.000Z",
  "count": 270,
  "snippets": [
    {
      "id": "3d8fa31f4b3a81e59084e09980d92c3b",
      "title": "The long middle, and attention as the destination",
      "type": "Excerpt",
      "year": "2026",
      "publication": "The Guardian",
      "source": "https://www.theguardian.com/society/2026/mar/22/...",
      "date": "2026-03-22",
      "tags": ["Language & ideas", "Health & body"],
      "text": "First paragraph.\n\nSecond paragraph."
    }
  ]
}
```

| Field | Notes |
|---|---|
| `id` | Notion page id, no dashes. Stable; use as the key for seen-list and favourites. |
| `title` | The `Clipping` property. A short label, not shown in the app for now. |
| `type` | One of Excerpt, Quote, Note, Poem, List. (`Image` rows are dropped: no body.) |
| `year` | Year the row was logged, **not** publication year. Don't use for filters. |
| `publication` | Null when blank. Bottom bar shows the icon + name only if present. |
| `source` | Null when blank. Bottom bar links the name only if present. |
| `date` | `Added` property = article publication date, `YYYY-MM-DD` or null. **Filters key off this.** |
| `tags` | Array, may be empty. |
| `text` | Paragraphs joined with `\n\n`. Render with `white-space: pre-line`. |

Sorted newest `date` first, nulls last.

## Filter semantics (as agreed)

Relative to today, on `date`:

- **Recent**: `date >= today − 3 months`
- **Past year**: `date >= today − 12 months`
- **Older**: `date < today − 12 months`
- Rows with `date: null` (~45% of the DB at time of first export) match no time filter. Either show them under **Older** or add an "Undated" bucket. Worth a decision before building the filter view.

## Audit notes from the first pull (21 Oct 2026)

- 286 rows in Notion (the schema note said 274; it has grown).
- About 130 rows have no `date`. Mostly Quotes, Notes, Poems and older Excerpts.
- Exact-body duplicates exist (e.g. "Pfas: in the blood of nearly every person on Earth", "Sandel on the two mistakes…", "The Tesla Files", "Liu Xiaobo", "The six traits of cool people", "Five words on one hand"). The exporter drops later copies by normalised body text. Near-duplicates with different wording ("The pub: cosy…" / "What makes a pub: cosy…", the two BBC-journalists rows, the two "600 millions de caméras" notes) are kept; tidy in Notion if wanted.
