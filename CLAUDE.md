# Chronicles

Personal PWA that shows one random press clipping at a time. Vite, React, TypeScript, pnpm. The clippings are a static JSON file in the repo; there is no backend. Seen-state lives in the browser's `localStorage`. Visual design: `docs/design/main-screen.md` and `docs/design/main-screen.png`; the scroll dissolve: `docs/design/quote-dissolve.md`.

## Git

- Commit directly on `main`. This repo has one maintainer and no outside contributors, so a branch and PR add nothing. Revert to branches and PRs if the repo ever takes outside contributions.
- Push as the personal GitHub account: `GH_TOKEN=$(gh auth token --user victormasson21) git push`. The active `gh` account is a work account with no access here.
- A push to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`. `base` in `vite.config.ts` is `/chronicle/` for the default Pages URL; set it to `/` once a custom domain is on.

## Commands

- `pnpm dev` — dev server on `localhost:5173`
- `pnpm test` — Vitest unit tests on the pure logic
- `pnpm lint` — oxlint
- `pnpm build` — type-check, then build `dist` with the PWA manifest, icons and service worker
- `pnpm export` — refresh `data/snippets.json` from Notion (needs `NOTION_TOKEN`; the `update-from-notion` skill owns the ritual)

## Data contract

`data/snippets.json` is generated by `scripts/export-notion.mjs`; `data/README.md` holds its schema and the filter semantics. Never hand-edit it. The snippet `id` is the key for the seen-list and future favourites, so it must stay stable.
